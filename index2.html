Comandos Git


        git init - Inicializa repósitorio e mantem um histórico.
    

        git status - Podemos visualizar o funcionamento correto do repósitorio.
    

        git add - Adiciona arquivos ao repósitorio.
        git add nome_pasta ou git add .
    

        git commit - Salva o estado atual do repósitorio.
        git commit -m "Mensagem de commit"
    

        git log - Irá exibir o histórico de commits.
        git log --oneline - Irá exibir o histórico de commits de forma resumida.
    

        git branch - Irá exibir branches existentes no repósitorio.
        git branch nome_da_branch - Cria uma nova branch.
        git checkout nome_da_branch - Irá alternar para a branch desejada.
        git branch -M main - Irá renomear a branch atual para main.

Git Remote


    git remote - Irá exibir os remotos existentes no repósitorio.
    git remote add origin url_do_repositorio - Irá adicionar um remoto ao repósitorio.
    git push origin main - Irá enviar os commits da branch main para o remoto origin.
    git remote add orign link_do_repositorio - Irá adicionar um remoto ao repósitorio.
    git remote -v - Irá exibir os remotos existentes no repósitorio.

Git Push


    git push - Eenviar alterações para o remote
    git push origin main - Ira enviar alterações para o remote
    git push -u origin main - Ira enviar alteracoes para o remote e
    definir a branch atual como upstream
